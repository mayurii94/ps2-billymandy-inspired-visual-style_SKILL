# Evidence library and provenance

The included PNG, JPG and JSON files carry the evidence used for the style checks. The names below identify the models measured in the original study.

| Measured model | Scope inspected |
|---|---|
| `Fred_Fredburger_Animations_FIXED.blend` | 26 base parts, materials/textures, 3 fixed views, recoloring intervention, 3 mvNorm frames |
| `Jack_PS2.blend` | Base Jack, excluding hidden H/V from style statistics; same view/intervention/motion tests |
| `PumpkinP_PS2.blend` | PmpknLa subset, 3 views and recoloring intervention; B variant not independently covered |
| `GrillO_PS2.blend` | 1 prop, 3 views and intervention; source material text |

Other reconstructed variants and level inventories were located but not all visually investigated. Fred/Jack/Pumpkin are not a representative architecture/terrain sample. Existing generated Hoss, knights, Di Lung, FoodTrailer and StiltHouse are not original-game evidence for this baseline.

`assets/references/measurements.json` contains input SHA256, bounding extents, mesh counts, modifier types, corner color statistics, material nodes, texture sizes/filtering/packing, camera directions and motion sample ranges. The JSON's action counts are whole-file counts including variants and old actions, not a verified count of unique source animations.

Source shader excerpts copied into `assets/source_text` identify texture/face transform and culling/modulation settings. `assets/references/*_black_removed.png` is a controlled intervention, never an original texture or an alternative accepted art style. `*_motion_*` retains the earlier scene's motion camera; it is useful for silhouette/expression inspection, not a spatially aligned cross-engine test.

`REFERENCE_HASHES.json` freezes the portable visual evidence. Texture PNGs are diagnostic copies generated by Blender.

No original gameplay footage or emulator render was used. Therefore claims concern actual source-derived reconstructions and selected source records; PS2 runtime equivalence is explicitly unresolved. Do not ship the reference textures/models as original newly authored game content.
