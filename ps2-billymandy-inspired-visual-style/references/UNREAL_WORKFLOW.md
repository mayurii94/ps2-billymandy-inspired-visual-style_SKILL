## Proven static path

`scripts/unreal_import_static.py` imports the original postbox demonstration, not arbitrary skeletal content. Set `STYLE_PROOF_DIR` to the directory generated by `build_mailbox.py`. Use an isolated fresh project made from `assets/unreal_template`, with PythonScriptPlugin and EditorScriptingUtilities enabled. It creates `/Game/StyleProof/Postbox_v2` assets and `/Game/StyleProof/Preview`; it refuses an existing mesh. For subsequent assets version the output package, do not bypass that protection globally.

```powershell
$env:STYLE_PROOF_DIR='<absolute-proof-output>'
& '<UE5.9>/Engine/Binaries/Win64/UnrealEditor-Cmd.exe' '<isolated>/StyleProof.uproject' '-ExecutePythonScript=<skill>/scripts/unreal_import_static.py' -unattended -nop4 -RenderOffscreen -d3d11
```

Use a correctly quoted complete argument for ExecutePythonScript. Unreal needs cache/plugin access outside a restricted workspace; request the required execution permission instead of circumventing the sandbox. NullRHI is insufficient here: UE5.9 explicitly refused MaterialEditingLibrary material compilation without a renderer. Save maps through `EditorLoadingAndSavingUtils.save_map`; `LevelEditorSubsystem.save_current_level_as` is not available in this installed version. These were real test failures, corrected in the delivered script.

The importer deliberately selects the legacy FBX path through `Interchange.FeatureFlags.Import.FBX 0` because it configures FbxImportUI. Keep that choice local to the isolated import session, or use and validate native Interchange options when integrating a new project. It combines static meshes, disables automatic material/texture generation, imports normals/tangents, uses unit conversion and imports source PNG separately. The Blender graph is rebuilt as two opaque single-sided unlit materials: sRGB texture into Emissive and a dark constant into Emissive. No lighting/bloom is needed to make this unlit asset visible. Black reversed hulls remain real geometry.

## Coordinates, scale and material contract

| Item | Tested contract / remaining work |
|---|---|
| Blender | Metres, +Z up, object front -Y; FBX forward -Y/up Z, apply unit scale, FBX_SCALE_UNITS |
| Unreal static result | Centimetres; Z unchanged, apparent horizontal handedness converted; postbox front +Y in the captured scene |
| Gameplay forward | UE gameplay often expects +X; rotate the placed static actor -90 degrees around Z if that is the project's convention. For skeletons bake/document the equivalent root convention and validate, not just rotate meshes independently |
| Size verification | v2 bounds 115.057644 × 85.284805 × 195.942835 cm; maximum bounds discrepancy 0.00000441 cm |
| UV and ink | 2 material slots, correct UV appearance and single-sided ink; never make the hull two-sided to repair culling |
| Color | PNG sRGB, bilinear sampling, unlit texture; reference capture disables tonemapping, adaptation, bloom, fog and motion blur |
| Vertex colors | Blender helper supports multiplication; proof atlas has no color modulation. For color-authored future assets enable import REPLACE and explicitly multiply VertexColor in Unreal; separately test linear/sRGB response |
| Transparency | Proof is opaque. Face/decal alpha and sorting require a tested masked/translucent material variant, not automatic graph translation |
| Skeleton/animation | Not validated by this static proof; export deform bones and baked actions, verify hierarchy, rest pose, root motion, slots and expression channel reconstruction |
| Collision/LOD/runtime | Not part of visual proof. Add suitable collision, decide hull LOD handling and profile target hardware before gameplay acceptance |

## Controlled appearance comparison

`unreal_capture.py` makes a 640² orthographic SceneCapture2D with matched bounds and camera, a show-only list containing the test actor and a black background. Tonemapper, EyeAdaptation, Bloom, MotionBlur, Fog and Atmosphere are disabled, render target gamma is 2.2. It captures at bounded ticks 60/120/180 and terminates the command-line session through the scripting keep-alive mechanism. Do not run this CLI lifecycle script unchanged in a user's interactive editor: use native capture tools or remove the keep-alive lifecycle and preserve the current level/view.

At the matched oblique view, silhouette IoU = **0.998853**, interior RGB mean absolute error = **2.739/255**, 95th percentile = **8/255**. These are diagnostics of this proof, not universal acceptance thresholds. Comparison uses black background, a >8/255 visible-pixel mask and a 3-pixel eroded intersection for interior colors. Edge filtering differs; global per-pixel identity is not claimed. See `assets/proof/BLENDER_UNREAL_COMPARISON.jpg` and `CROSS_ENGINE_QA.json`.

This validates the static atlas-plus-inverted-hull appearance in the documented diagnostic setup. It does NOT validate default UE tonemapping, the existing ThirdPerson map, gameplay exposure, temporal AA, new skeletal assets, face state runtime control or performance. Before production integration implement project-local camera/postprocess settings and compare again; don't globally disable effects without regard to the rest of the game.

## Extending to characters

Export only the intended deformation hierarchy; bake supported actions at the project's FPS and verify units/root transform before bulk import. One skeleton asset per compatible bind hierarchy; do not reuse a skeleton just because bone names overlap. Recreate face-atlas offsets as parameters/material instances, drive discrete state values from animation curves or events, and verify mouth/eye UV regions separately. Test mesh and shell deformations at the same frames in both engines. These are required next-stage checks, not tested features of the current scripts.
